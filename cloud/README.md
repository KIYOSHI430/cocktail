# 数据上云 · 部署手册

环境 ID：`cocktail-d1gk02vdl123a2e05`

整个过程分三大步：**① 建集合 → ② 导入数据 → ③ 部署云函数**。全部在腾讯云开发控制台里点，不需要改代码。

---

## 第一步：建 7 个数据库集合

进入云开发控制台 → 左侧「**数据库**」→ 点「**新建集合**」，依次建这 7 个（名字必须一模一样，区分大小写）：

```
ingredients    材料库
recipes        配方库
users          用户
comments       评论
posts          帖子
reports        勘误（先建空集合）
settings       站点设置
sessions       登录会话（先建空集合）
```

建完后，把每个集合的**权限**都设置成：

> **数据库 → 选中集合 → 权限设置 → 自定义安全规则**，填这一句：

```json
{ "read": false, "write": false }
```

**为什么设成谁都不能读写？** 因为所有读写都要经过云函数，云函数用的是管理员权限，不受这条规则限制。这样前端拿不到数据库，别人就算拿到你的环境 ID 也偷不走数据。

> `settings` 集合可以稍微宽松一点，但设成 false 也没问题（云函数会处理）。

---

## 第二步：把数据导进去

项目里 `cloud/data/` 目录下已经准备好了 6 个文件，**在控制台里逐个导入**：

| 集合 | 导入这个文件 | 条数 |
| --- | --- | --- |
| ingredients | `cloud/data/ingredients.jsonl` | 192 条材料 |
| recipes | `cloud/data/recipes.jsonl` | 115 款配方 |
| users | `cloud/data/users.jsonl` | 2 个账号 |
| comments | `cloud/data/comments.jsonl` | 2 条示例评论 |
| posts | `cloud/data/posts.jsonl` | 2 条示例帖 |
| settings | `cloud/data/settings.jsonl` | 1 条站点设置 |

**导入方法**：数据库 → 选中集合 → 点右上角「**导入**」→ 选择对应的 `.jsonl` 文件 → 冲突处理选「**插入**」→ 确定。

> 如果控制台要求 `.json` 而不是 `.jsonl`：先把 `.jsonl` 重命名成 `.json` 再传（内容格式是一样的，都是一行一个对象）。

导入完成后，点开 `ingredients` 集合应该能看到 192 条记录，`recipes` 有 115 条。

---

## 第三步：部署云函数 `api`

1. 左侧「**云函数**」→「**新建云函数**」
2. 函数名填 **`api`**（必须叫这个），运行环境选 **Node.js 18**
3. 代码来源选「**在线编辑**」，把项目里 `cloud/api/index.js` 的内容**整段粘贴**进去
4. 在同一个页面找到「**依赖管理**」或 `package.json` 编辑，确保有这一条依赖（没有的话手动加上）：

   ```json
   { "dependencies": { "@cloudbase/node-sdk": "^2.9.0" } }
   ```

5. 点「**保存并安装依赖**」，等安装完成
6. 点「**测试**」跑一次，事件模板里填：

   ```json
   { "action": "ping" }
   ```

   应该返回类似 `{"ok":true,"data":{"env":"cocktail-...","time":...}}`，说明函数跑起来了。

### 给云函数开一个网址（HTTP 访问服务）

1. 云开发控制台左侧「**HTTP 访问服务**」（有的环境在「环境 → 访问服务」里）
2. 新建一条路径：**路径填 `/api`**，指向云函数 **`api`**
3. 保存后你会拿到一个地址，形如：

   ```
   https://cocktail-d1gk02vdl123a2e05.service.tcloudbase.com/api
   ```

4. **验证**：在浏览器里直接打开这个地址加参数：

   ```
   https://cocktail-d1gk02vdl123a2e05.service.tcloudbase.com/api?action=ping
   ```

   能看到 `{"ok":true,...}` 就说明通了。**把地址发给我，我就把前端切到云端。**

## 关于费用

云开发的计费按「数据库读写次数 + 存储 + 云函数调用次数」算，都有免费额度。

我们这个量级（几百个用户、每天几百次请求）**基本都在免费额度内**。等真有几千用户之后，每月大概几元到几十元。短信和 AI 是单独计费的（短信约 0.04 元/条，AI 每万条帖子几毛钱）。
