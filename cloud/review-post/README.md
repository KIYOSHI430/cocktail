# 帖子 AI 审核云函数

网站后台的「AI 审核云函数地址」填的就是这里部署出来的地址。

## 为什么必须放在云函数里

调用大模型需要 API Key。**Key 绝对不能写进网页代码**——你的仓库是公开的，任何人按 F12 就能看到并盗刷你的额度。

正确结构：

```
浏览器（发帖） ──► 云函数（持有 Key） ──► 大模型 API
                      │
                      └─► 返回 { risk: 0-100, reasons: [...] }
```

## 部署步骤（腾讯云开发 CloudBase）

1. 在 [腾讯云开发控制台](https://console.cloud.tencent.com/tcb) 新建或进入你的环境
2. 左边选「云函数」→ 新建云函数，名字填 `review-post`，运行环境选 Node.js 16 或 18
3. 把本目录的两个文件（`index.js`、`package.json`）上传上去（或直接在线编辑粘贴 `index.js` 内容）
4. 在云函数配置里添加**环境变量**：

   | 变量名 | 说明 | 例子 |
   | --- | --- | --- |
   | `AI_API_KEY` | 模型服务的 Key（必填） | `sk-xxxxxxxx` |
   | `AI_BASE_URL` | 接口地址（选填） | `https://ark.cn-beijing.volces.com/api/v3` |
   | `AI_MODEL` | 模型名（选填） | `doubao-lite-32k` |

5. 给云函数开启「HTTP 访问服务」（云开发控制台里可以拿到一个 `https://xxx.service.tcloudbase.com/review-post` 地址）
6. 回到网站：管理后台 → 站点设置 → 打开「启用 AI 复核」→ 把地址粘到「AI 审核云函数地址」→ 保存

之后每次有人发帖，先走本地规则，再把内容发给这个云函数复核；审核结果（含风险分和理由）会显示在「帖子审核」里。

## 各平台怎么选（都很便宜，部分有免费额度）

| 平台 | 模型 | 特点 |
| --- | --- | --- |
| 腾讯混元 | `hunyuan-lite` | 和腾讯云开发同账号，一次实名搞定，有免费额度，**最省事** |
| 火山方舟（豆包） | `doubao-lite-32k` | 就是你说的豆包，新用户有赠送额度，lite 版极便宜 |
| 智谱 GLM | `glm-4-flash` | 有免费额度，中文不错 |
| DeepSeek | `deepseek-chat` | 便宜、判断力强，无免费额度 |

具体免费额度和单价请以各平台当期页面为准（会变）。

## 成本估算

一条帖子的审核请求大约消耗 **400~600 tokens**（含提示词）。

- 按豆包 lite 的价位（输入约 ¥0.3/百万 tokens 量级），**1 万条帖子大约几毛钱**
- 如果开启「智能审核」，只有规则判断不出来（中等风险）的内容才需要送 AI，成本还能再降

## 建议的三层审核

1. **规则层**（0 成本，已经内置）：广告词、微信/QQ/手机号、违法词、刷屏重复 → 直接拦或转人工
2. **AI 层**（可选）：规则判断不出来的，交给模型算风险分
3. **人工层**：管理员在后台复核、改判、必要时填拒绝原因

这样既省钱，又不会让明显违规的内容漏出去。

## 本地测试

```bash
const f = require('./index.js');
f.main({title:'新手求教：金酒怎么选', content:'想入门调酒，有平价推荐吗', category:'求助'})
 .then(r => console.log(r));
"
```
