# 帖子 AI 审核云函数（腾讯混元版）

网站后台「站点设置 → AI 审核云函数地址」填的就是这里部署出来的地址。

## 为什么必须放在云函数里

调用大模型需要 Key。**Key 绝对不能写进网页代码**——这个仓库是公开的，任何人按 F12 就能看到并盗刷你的额度。

```
浏览器（发帖） ──► 云函数（Key 存在环境变量里） ──► 腾讯混元
                       └─► 返回 { risk: 0-100, reasons: [...] }
```

## 审核规则（已按你的要求写死）

| 规则 | 判定 | 风险分 | 结果 |
| --- | --- | --- | --- |
| 广告（卖货、代购、招商、留微信/QQ/电话、拉群、推广链接） | 命中 | 80–100 | 直接拦下 |
| 色情（低俗、擦边、性暗示） | 命中 | 80–100 | 直接拦下 |
| 暴力（斗殴、伤害、恐吓、毒品枪支） | 命中 | 80–100 | 直接拦下 |
| 辱骂（脏话、人身攻击、地域歧视） | 命中 | 60–79 | 转人工复核 |
| 灌水（与调酒无关、无意义重复） | 命中 | 30–49 | 转人工复核 |
| 正常交流（求助 / 分享 / 心得 / 器材 / 晒作品） | — | 0–19 | 直接发布 |

想改规则不用改代码：在云函数的**环境变量**里加一个 `AI_SYSTEM_PROMPT`，内容整体替换默认规则即可。

## 部署步骤（约 15 分钟）

### 第一步：拿到混元的 API Key

1. 登录腾讯云控制台（没账号先注册，需要**实名认证**）
2. 搜索进入「腾讯混元大模型」控制台
3. 在「API Key」页面创建一个 Key，复制保存（形如 `sk-xxxx`）

> 如果提示要先开通服务，按提示开通即可。`hunyuan-lite` 属于最便宜的档位，通常有免费额度，具体以页面当期说明为准。

### 第二步：建云函数

1. 进入云开发 CloudBase 控制台，新建或进入一个环境（按量付费的免费额度就够）
2. 左侧「云函数」→「新建云函数」
3. 函数名填 `review-post`，运行环境选 Node.js 18
4. 代码来源选「在线编辑」，把本目录 `index.js` 的内容整段粘贴进去（这函数零依赖，`package.json` 保持默认也行）
5. 保存并部署

### 第三步：配置环境变量

在云函数详情页找到「环境变量」，添加：

| 变量名 | 必填 | 值 |
| --- | --- | --- |
| AI_API_KEY | 是 | 第一步拿到的 Key |
| AI_MODEL | 否 | hunyuan-lite（默认就是它） |
| AI_BASE_URL | 否 | 默认 https://api.hunyuan.cloud.tencent.com/v1 |

想换成豆包：`AI_BASE_URL=https://ark.cn-beijing.volces.com/api/v3` + `AI_MODEL=doubao-lite-32k`，代码不用改。

### 第四步：开启 HTTP 访问

1. 云开发控制台左侧「HTTP 访问服务」（或云函数里的访问服务）给 `review-post` 开一条路径
2. 拿到形如 `https://xxxx.service.tcloudbase.com/review-post` 的地址
3. 回到网站后台：站点设置 → 勾选「启用 AI 复核」→ 粘贴到这个地址 → 保存

### 第五步：验证

- 发一条带「加微信」的帖子：规则层会直接拦下（这一步不需要 AI，已经生效）
- 发一条「你这人真垃圾」：应该进入**待审核**，后台能看到 AI 给出的风险分和理由

## 本地测试

```bash
AI_API_KEY=你的key node -e "
const f = require('./index.js');
f.main({title:'新手求教：金酒怎么选', content:'想入门调酒，有平价推荐吗', category:'求助'}).then(console.log);
f.main({title:'低价出售洋酒', content:'加我微信 abc123，顺丰包邮'}).then(console.log);
"
```

没配 `AI_API_KEY` 时函数会返回 `risk: 40`（转人工），不会让用户卡住。

## 成本

- 每条帖子一次请求约 400–600 tokens
- `hunyuan-lite` 是混元里最便宜的档位，还有免费额度，**正常社区量级基本花不了几块钱**
- 更省的做法：只有规则层判断不出来的内容才送 AI —— 现在的流程已经是这样（明显违规本地就拦掉了）
