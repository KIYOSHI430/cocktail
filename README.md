# 鸡尾酒法典 · 调酒灵感（原型版）

一个参考微信小程序「今晚喝什么-调酒灵感」思路做的调酒网站原型。

> 站点名称、标语都可以在「管理后台 → 站点设置」里随时修改，改完顶栏和浏览器标题会同步更新。

## 怎么打开

**最简单的办法：直接双击 `index.html`**，用 Chrome / Edge 打开就能用，不用装任何东西。

想用手机一起看，可以在本文件夹执行 `node serve.js`，然后手机浏览器访问电脑的局域网地址（见文件内说明）。

## 账号

| 角色 | 用户名 | 密码 | 说明 |
| --- | --- | --- | --- |
| **管理员** | `admin` | `Cocktail@2026` | 站点最高权限账号，昵称「站长」 |
| 普通用户 | `demo` | `123456` | 演示用普通账号 |

任何人都可以自己点「注册」创建普通账号。管理员可以在后台把某个用户**提升为管理员**，也可以取消；系统会保证至少保留一个管理员。

> 建议登录后在「管理后台 → 用户管理 → 编辑资料」里把管理员密码改成你自己的，并且**不要**把这个网址直接放到公网（见文末「关于数据存储」）。

## 权限区分（重点）

| 能做的事 | 游客 | 普通用户 | 管理员 |
| --- | :---: | :---: | :---: |
| 浏览配方库、材料库、评论区 | ✅ | ✅ | ✅ |
| 收藏、勾选自己的材料 | — | ✅ | ✅ |
| 发布经典 / 特调配方 | — | ✅ | ✅ |
| 推荐 / 补充教学视频 | — | ✅ | ✅ |
| 评论、回复、点赞 | — | ✅ | ✅ |
| 删除自己的评论 / 配方 | — | ✅（可关闭） | ✅ |
| 材料库增删改 | — | — | ✅ |
| 配方审核 / 下架 / 删除任何配方 | — | — | ✅ |
| 评论置顶 / 隐藏 / 删除 | — | — | ✅ |
| 用户与管理员权限管理 | — | — | ✅ |
| 站点设置、数据备份还原 | — | — | ✅ |

普通用户的写操作**只限于「发布配方」「推荐视频」「评论」**和自己的内容，碰不到别人的配方、材料库和站点设置。管理员在后台可以逐项开关这些权限（例如临时关闭评论、要求配方先审核）。

## 功能清单

### 用户侧
- 自由注册 / 登录 / 退出
- **手机端体验**：窄屏下顶栏只保留站点名和右上角的菜单按钮，导航（配方库 / 想喝啥 / 我有啥 / 添加配方 / 我的 / 管理后台）全部收进抽屉菜单，点开就是一条条带图标和说明的入口，不再挤成一坨
- **配方库**：关键词搜索（支持多个关键词、空格分隔、结果高亮）、经典 / 特调切换、按**基酒**筛选、按**酒感**筛选、只看收藏、只看「我有的材料能调的酒」、5 种排序（最热 / 最新 / 匹配度 / 最容易做 / 名称）
- **想喝啥**（按口味点单）：28 个口味标签分 5 组（口味 / 口感 / 长度 / 酒感 / 场合），随便点几个就能筛出想喝的那类；支持「同时满足全部」和「满足任一即可」两种模式，还有 **🎲 随机来一杯**——从符合标签的酒里抽一杯，专治选择困难。卡片和详情页上的标签都可以直接点，点了就跳到这里自动筛好
- **我有啥**：勾选手头材料 → 分档列出「现在就能调 / 差 1 种 / 差 2 种 / 差 3 种」；**材料搜索**（中文名 + 英文别名 + 分类）、按分类全选 / 取消、已选材料条可点击移除、**🛒 补货推荐**（告诉你再买哪几样最划算，能多解锁几款酒）
- **配方详情**：材料清单（标出有 / 缺 / 可选）、做法步骤、教学视频外链、收藏、浏览量、评论数
- **评论区**（参考视频网站）：
  - 发表评论（500 字以内）、二级回复、点赞
  - 头像 + 昵称 + 时间（刚刚 / N 分钟前 / 昨天…）+ 身份标签
  - 按「最热 / 最新」排序，置顶评论永远在最前
  - 加载更多（每次 10 条）
  - 自己的评论可以删除；被管理员隐藏的评论只有管理员和本人能看到
- **添加配方**：必填**配方图片**（上传或贴链接，自动压缩）、**材料**（从材料库点选，可填用量、可标记「装饰用」）、**调酒步骤**（一行一步）、**口味标签**（勾选或自己写，最多 10 个）；B 站等教学视频是选填项
- **我的**：身份与权限说明、选中的材料、收藏、发布的配方、发过的评论
- **🎲 随便来一杯**：按你有的材料随机推荐

### 管理侧（admin 登录后点「管理后台」）
- **材料管理**：新增 / 编辑 / 删除（名称、分类、图标、英文别名、是否常备材料）；删除材料时用到它的配方会自动同步
- **配方管理**：查看、审核通过、下架、删除，并显示每款配方的评论数
- **评论管理**：评论概览（总数 / 今日新增 / 已隐藏 / 置顶 / 参与用户）、按内容 / 用户名 / 配方名搜索、只看已隐藏、置顶 / 隐藏 / 删除
- **用户管理**：权限说明、编辑昵称简介、重置密码、设为 / 取消管理员、删除账号
- **站点设置**：站点名称与标语，7 个权限开关（发布配方、配方审核、推荐视频、发表评论、编辑自己的配方、删除自己的配方、删除自己的评论）
- **数据备份**：导出 / 导入 JSON、恢复初始数据

## 内置数据

- **167 种调酒材料**，分 7 类：基酒、利口酒、果汁与饮料、糖浆与调味、新鲜水果、香草与装饰、其他（冰块等标为「常备材料」，不参与匹配计算）
- **85 款配方**：76 款经典鸡尾酒（金汤力、干马天尼、尼格罗尼、莫吉托、玛格丽特、新加坡司令、僵尸、盘尼西林、飞行、B-52……）+ 9 款特调示例（含青梅气泡、山楂金酒酸、枸杞桂圆威士忌等中式特调）
- **每款酒都带口味标签**（甜 / 酸 / 苦 / 气泡 / 长饮 / 微醺 / 夏日……），可以按口味挑酒，也可以让系统随机抽
- **63 款配方已配成品图**，其余 22 款（多数是自创特调）暂时显示 emoji 卡片，可随时在后台补图
- 部分配方已带 B 站教学视频链接，其余可以在详情页一键推荐
- 内置几条示例评论，方便直接看到评论区的样子

## 配方图片

卡片列表用的是缩略图（约 8–13KB，懒加载），详情页用大图，都做了**加载失败自动回退**：图挂了就显示原来的 emoji + 渐变卡片，不会出现破图。

目前这 63 张演示图片来自公开鸡尾酒数据库 [TheCocktailDB](https://www.thecocktaildb.com/)，只是为了让版面先丰满起来。**正式上线前建议换成自己拍的照片**，原因有两个：一是版权更干净，二是自家照片风格统一、更像个正经产品。

换图入口有两个，都只能管理员操作：

1. **管理后台 → 配方管理 → 换图**：可以贴图片链接，也可以直接上传本地图片（前端会自动压缩到 1000px 以内再存）
2. **配方详情页右上角的「🖼 换图」按钮**：改当前这一款

配方管理页顶部会显示"还有几款没配图"，方便你按进度补完。以后接了腾讯云开发，上传的图片会改成存到云存储，不再受浏览器本地空间限制。

## 口味标签体系

标签分 5 组共 28 个，全部内置好了，85 款酒也都打了标签：

| 分组 | 标签 |
| --- | --- |
| 😋 口味 | 甜 酸 苦 涩 咸 辣 果香 奶香 咖啡 草本 烟熏 清爽 |
| 🫧 口感 | 气泡 浓郁 绵密 冰沙 |
| ⏳ 长度 | 长饮 短饮 |
| 🥴 酒感 | 无酒精 微醺 中等 烈 |
| 🎉 场合 | 餐前 餐后 派对 独饮 夏日 冬日 |

几个用例：**「酸 + 气泡 + 夏日」** → 18 款清爽的夏日酒；**「无酒精」** → 不喝酒的人也能有得选；**「餐后 + 咖啡」** → 饭后甜点酒。标签按钮上带数字，是那个标签下有多少款酒。

用户发配方时可以**自由勾选**，也可以自己敲一个新标签（比如「家乡味」「烟熏味」），自定义标签会自动进入词库，之后所有人都能用来筛选。

## 上传配方的必填项

为了让新发上来的配方都完整可看，这四项是必填的：

1. **酒名**（英文名选填）
2. **配方图片** —— 上传手机里的照片，或者贴一个图片链接
3. **材料** —— 从材料库点选，可填用量、可标记「装饰用」
4. **调酒步骤** —— 一行一步
5. **口味标签** —— 至少 1 个，最多 10 个

**选填的有三项**：英文名、**图标 emoji**（留空会自动用第一个材料的图标，实在没有就用 🍹）、教学视频（B 站链接）。发出去之后任何用户还能继续在详情页推荐视频。

## 界面风格

整体走"深夜酒吧菜单"的路线：墨黑底色 + 古金点缀，标题用衬线字体（宋体 / Georgia），正文用无衬线保证易读，卡片带图片、标签和细金线分隔。窄屏和宽屏都做了适配——手机上两列卡片、大号点击区域，桌面上四列卡片、更宽松的留白。

## 版本升级说明

如果你之前打开过第一版，浏览器里已经存了老数据。新版启动时会**自动升级**：

保留你的账号、自己发布的配方、收藏、勾选的材料和站点设置，然后把新增的材料、配方、评论区补进去；如果管理员密码还是旧的 `admin123`，会统一升级成 `Cocktail@2026`。

## 关于数据存储（重要）

原型阶段所有数据都保存在**当前浏览器的 localStorage** 里：

- 换浏览器、换电脑、清缓存会看不到数据，请用「管理后台 → 数据备份」导出 JSON；
- 密码是明文存在本机，**只适合自己本地玩，不要放公网**；
- 想让多人共享同一份数据，需要下一步接后端（见下）。

## 下一步路线（已确定走腾讯云开发）

现在的网站是**纯前端**：账号、配方、评论都存在每个访客自己的浏览器里，所以它还不能算"真正上线可用"的网站——你和朋友看到的是两份互不相干的数据。接上腾讯云开发（CloudBase）之后，数据会集中存在云数据库里，所有人都读写同一份，登录方式也能扩展成手机号 / 微信 / QQ。

| 阶段 | 要做什么 | 说明 |
| --- | --- | --- |
| 1. 数据上云 | 云数据库建表（用户 / 材料 / 配方 / 评论 / 点赞 / 收藏），前端 `store.js` 改成调 CloudBase SDK | 只改数据层，界面代码基本不动 |
| 2. 账号体系 | 手机号验证码登录；微信 / QQ 登录（需要开放平台资质，见下方提醒） | 密码改成云端哈希，不再明文 |
| 3. 图片上云 | 换图时改为上传到云存储，返回 fileID | 不再受浏览器本地空间限制 |
| 4. 对外发布 | 云开发自带默认域名（免备案），也可绑定自己的域名 | 微信内分享、扫码访问都方便 |

### ⚠️ 登录方式的资质提醒（很重要，先看再决定）

| 登录方式 | 可行性 | 门槛 |
| --- | --- | --- |
| 手机号验证码 | ✅ 个人可做 | 腾讯云短信需实名，短信签名要审核（按条计费，约几分钱一条） |
| 微信登录（**网站**扫码） | ❌ 个人做不了 | 微信开放平台的"网站应用"只对企业/个体工商户开放，认证费 300 元/年 |
| 微信公众号 H5 登录 | ❌ 个人做不了 | 需要认证的服务号 |
| 微信登录（**小程序**内） | ✅ 个人可做 | 个人可以注册小程序，登录能力在小程序内可用 |
| QQ 登录 | ⚠️ 需确认 | QQ 互联要求网站已备案，审核较严 |

**结论**：如果你现在是个人的话，纯网站形态最现实的是**手机号验证码登录 + 邮箱/密码登录**；想在微信生态里用微信登录，更顺的路是**把界面打包成微信小程序**（现在这套界面和逻辑都是移动端适配的，用 uni-app 或 Taro 可以复用）。
