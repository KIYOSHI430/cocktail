# 今晚喝什么 · 调酒灵感（原型版）

一个参考微信小程序「今晚喝什么-调酒灵感」思路做的调酒网站原型。

## 怎么打开

**最简单的办法：直接双击 `index.html`**，用 Chrome / Edge 打开就能用，不用装任何东西。

想用手机一起看，可以在本文件夹执行 `node serve.js`，然后手机浏览器访问电脑的局域网地址（见文件内说明）。

## 默认账号

| 角色 | 用户名 | 密码 |
| --- | --- | --- |
| 管理员 | admin | admin123 |
| 普通用户 | demo | 123456 |

也可以直接用「注册」按钮创建自己的账号，任何人都能注册。

## 已经做好的功能

### 用户侧
- 自由注册 / 登录 / 退出（顶栏右上角）
- **配方库**：搜索酒名或材料、按「经典 / 特调」筛选、按热门或最新排序、收藏
- **我有啥**：勾选手头材料 → 自动分档列出「现在就能调 / 差 1 种 / 差 2 种 / 差 3 种」，每款酒还差什么材料直接标出来
- **配方详情**：材料清单（会标出你有 / 缺 / 可选）、做法步骤、教学视频外链、收藏、浏览量
- **添加配方**：任何人都能发布「经典鸡尾酒」或「特调」，材料从材料库点选，可填用量、可标记为装饰用
- **补充视频**：任何登录用户都可以给配方补充 / 修改教学视频链接
- **🎲 随便来一杯**：根据你有的材料随机推荐
- **我的**：我选中的材料、我的收藏、我发布的配方

### 管理侧（用 admin 登录后点「管理后台」）
- **材料管理**：新增 / 编辑 / 删除材料（名称、分类、图标、别名、是否常备材料）。删除材料时，用到它的配方会自动同步
- **配方管理**：查看、审核通过、下架、删除用户发布的配方
- **用户管理**：设置 / 取消管理员、删除账号
- **站点设置**：站点名称与标语、是否允许用户自助发布、用户发布的配方是否需要审核、是否允许用户补充视频
- **数据备份**：一键导出 / 导入 JSON，或恢复初始数据

## 材料库

预置了 **83 种常见材料**，分 7 类：基酒、利口酒、果汁与饮料、糖浆与调味、新鲜水果、香草与装饰、其他（冰块这类标为「常备材料」，不参与匹配计算）。预置了 **26 款经典鸡尾酒 + 5 款特调示例**，其中部分配方已带上 B 站教学视频链接，其余可以由你或用户在详情页一键补充。

## 关于数据存储（重要）

原型阶段所有数据都保存在**当前浏览器的 localStorage** 里：

- 换浏览器、换电脑、清缓存会看不到数据，请用「管理后台 → 数据备份」导出 JSON；
- 密码也是明文存在本机，**只适合自己本地玩，不要放公网**；
- 想让多人共享同一份数据，需要下一步接后端（见下）。

## 下一步可以怎么升级

1. **加后端**：Node/Express + SQLite（或 Supabase / 微信云开发），把 `assets/js/store.js` 里那些函数原样改成接口请求，界面层 `app.js` 不用大改；
2. **账号安全**：密码加盐哈希、手机号 / 微信登录、找回密码；
3. **图片**：给配方加真实成品图（现在是 emoji + 渐变色块占位），支持用户上传；
4. **更聪明的匹配**：支持材料替代（比如君度 ⇄ 白橙皮利口酒）、按口味 / 酒精浓度 / 场合推荐；
5. **社交**：配方点赞、评论、评分、关注作者、排行榜；
6. **打包成小程序 / App**：界面已经是移动端适配的，可用 uni-app 或 Taro 复用逻辑重写一遍。
