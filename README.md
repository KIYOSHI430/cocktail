# 鸡尾酒法典 · 调酒灵感（原型版）

一个参考微信小程序「今晚喝什么-调酒灵感」思路做的调酒网站原型。

> 站点名称、标语都可以在「管理后台 → 站点设置」里随时修改，改完顶栏和浏览器标题会同步更新。

## 怎么打开

**最简单的办法：直接双击 `index.html`**，用 Chrome / Edge 打开就能用，不用装任何东西。

想用手机一起看，可以在本文件夹执行 `node serve.js`，然后手机浏览器访问电脑的局域网地址（见文件内说明）。

## 账号

| 角色 | 用户名 | 密码 | 说明 |
| --- | --- | --- | --- |
| **管理员** | `admin` | `Cocktail@2026` | 站点最高权限账号，昵称「站长」 |
| 普通用户 | `demo` | `123456` | 演示用普通账号 |

任何人都可以自己点「注册」创建普通账号。管理员可以在后台把某个用户**提升为管理员**，也可以取消；系统会保证至少保留一个管理员。

> 建议登录后在「管理后台 → 用户管理 → 编辑资料」里把管理员密码改成你自己的，并且**不要**把这个网址直接放到公网（见文末「关于数据存储」）。

## 权限区分（重点）

| 能做的事 | 游客 | 普通用户 | 管理员 |
| --- | :---: | :---: | :---: |
| 浏览配方库、材料库、评论区 | ✅ | ✅ | ✅ |
| 收藏、勾选自己的材料 | — | ✅ | ✅ |
| 发布经典 / 特调配方 | — | ✅ | ✅ |
| 推荐 / 补充教学视频 | — | ✅ | ✅ |
| 评论、回复、点赞 | — | ✅ | ✅ |
| 删除自己的评论 / 配方 | — | ✅（可关闭） | ✅ |
| 材料库增删改 | — | — | ✅ |
| 配方审核 / 下架 / 删除任何配方 | — | — | ✅ |
| 评论置顶 / 隐藏 / 删除 | — | — | ✅ |
| 用户与管理员权限管理 | — | — | ✅ |
| 站点设置、数据备份还原 | — | — | ✅ |

普通用户的写操作**只限于「发布配方」「推荐视频」「评论」**和自己的内容，碰不到别人的配方、材料库和站点设置。管理员在后台可以逐项开关这些权限（例如临时关闭评论、要求配方先审核）。

## 功能清单

### 用户侧
- 自由注册 / 登录 / 退出
- **配方库**：关键词搜索（支持多个关键词、空格分隔、结果高亮）、经典 / 特调切换、按**基酒**筛选、按**酒感**筛选、只看收藏、只看「我有的材料能调的酒」、5 种排序（最热 / 最新 / 匹配度 / 最容易做 / 名称）
- **我有啥**：勾选手头材料 → 分档列出「现在就能调 / 差 1 种 / 差 2 种 / 差 3 种」；**材料搜索**（中文名 + 英文别名 + 分类）、按分类全选 / 取消、已选材料条可点击移除、**🛒 补货推荐**（告诉你再买哪几样最划算，能多解锁几款酒）
- **配方详情**：材料清单（标出有 / 缺 / 可选）、做法步骤、教学视频外链、收藏、浏览量、评论数
- **评论区**（参考视频网站）：
  - 发表评论（500 字以内）、二级回复、点赞
  - 头像 + 昵称 + 时间（刚刚 / N 分钟前 / 昨天…）+ 身份标签
  - 按「最热 / 最新」排序，置顶评论永远在最前
  - 加载更多（每次 10 条）
  - 自己的评论可以删除；被管理员隐藏的评论只有管理员和本人能看到
- **添加配方**：材料从材料库点选、可填用量、可标记「装饰用」
- **我的**：身份与权限说明、选中的材料、收藏、发布的配方、发过的评论
- **🎲 随便来一杯**：按你有的材料随机推荐

### 管理侧（admin 登录后点「管理后台」）
- **材料管理**：新增 / 编辑 / 删除（名称、分类、图标、英文别名、是否常备材料）；删除材料时用到它的配方会自动同步
- **配方管理**：查看、审核通过、下架、删除，并显示每款配方的评论数
- **评论管理**：评论概览（总数 / 今日新增 / 已隐藏 / 置顶 / 参与用户）、按内容 / 用户名 / 配方名搜索、只看已隐藏、置顶 / 隐藏 / 删除
- **用户管理**：权限说明、编辑昵称简介、重置密码、设为 / 取消管理员、删除账号
- **站点设置**：站点名称与标语，7 个权限开关（发布配方、配方审核、推荐视频、发表评论、编辑自己的配方、删除自己的配方、删除自己的评论）
- **数据备份**：导出 / 导入 JSON、恢复初始数据

## 内置数据

- **167 种调酒材料**，分 7 类：基酒、利口酒、果汁与饮料、糖浆与调味、新鲜水果、香草与装饰、其他（冰块等标为「常备材料」，不参与匹配计算）
- **85 款配方**：76 款经典鸡尾酒（金汤力、干马天尼、尼格罗尼、莫吉托、玛格丽特、新加坡司令、僵尸、盘尼西林、飞行、B-52……）+ 9 款特调示例（含青梅气泡、山楂金酒酸、枸杞桂圆威士忌等中式特调）
- 部分配方已带 B 站教学视频链接，其余可以在详情页一键推荐
- 内置几条示例评论，方便直接看到评论区的样子

## 版本升级说明

如果你之前打开过第一版，浏览器里已经存了老数据。新版启动时会**自动升级**：

保留你的账号、自己发布的配方、收藏、勾选的材料和站点设置，然后把新增的材料、配方、评论区补进去；如果管理员密码还是旧的 `admin123`，会统一升级成 `Cocktail@2026`。

## 关于数据存储（重要）

原型阶段所有数据都保存在**当前浏览器的 localStorage** 里：

- 换浏览器、换电脑、清缓存会看不到数据，请用「管理后台 → 数据备份」导出 JSON；
- 密码是明文存在本机，**只适合自己本地玩，不要放公网**；
- 想让多人共享同一份数据，需要下一步接后端（见下）。

## 下一步可以怎么升级

1. **加后端**：Node/Express + SQLite（或 Supabase / 微信云开发），把 `assets/js/store.js` 里的函数改成接口请求，`app.js` 基本不用动；
2. **账号安全**：密码加盐哈希、微信 / 手机号登录、找回密码、评论举报与敏感词过滤；
3. **图片**：给配方加真实成品图（现在是 emoji + 渐变色块占位），支持用户上传；
4. **更聪明的匹配**：材料替代（君度 ⇄ 白橙皮利口酒）、按口味 / 场合 / 预算推荐、购物清单导出；
5. **社交**：配方点赞评分、关注作者、排行榜、分享海报；
6. **打包成小程序 / App**：界面已经是移动端适配的，可用 uni-app 或 Taro 复用逻辑重写一遍。
