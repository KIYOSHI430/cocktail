# 鸡尾酒法典 · 调酒灵感（原型版）

一个参考微信小程序「今晚喝什么-调酒灵感」思路做的调酒网站原型。

> 站点名称、标语都可以在「管理后台 → 站点设置」里随时修改，改完顶栏和浏览器标题会同步更新。

## 怎么打开

**最简单的办法：直接双击 `index.html`**，用 Chrome / Edge 打开就能用，不用装任何东西。

想用手机一起看，可以在本文件夹执行 `node serve.js`，然后手机浏览器访问电脑的局域网地址（见文件内说明）。

## 账号

| 角色 | 用户名 | 密码 | 说明 |
| --- | --- | --- | --- |
| **管理员** | 你的手机号 | 你自己设定的密码 | 站点最高权限账号，昵称「站长」 |
| 普通用户 | `demo` | `123456` | 演示用普通账号 |

任何人都可以用手机号自己注册。管理员可以在后台把某个用户**提升为管理员**，也可以取消；系统会保证至少保留一个管理员。

### 密码安全（重要）

- 密码**不以明文保存**：存的是「随机 salt + 12000 次迭代 SHA-256」的哈希，登录时重新算一遍比对。同一密码每次注册都会得到不同的哈希。
- **但请注意**：这个哈希是写在**公开仓库**里的，理论上可以被人离线暴力破解。所以：
  - 上线后请用强一点的密码（长度 ≥ 12 位、大小写数字混合）
  - 接上后端之后，密码应该改由服务端用 `bcrypt`/`scrypt` 处理，前端不再参与
- 想改密码：登录后「我的 → 修改密码」，或「管理后台 → 用户管理 → 编辑资料」，**都不需要在代码里写明文**

> 建议登录后在「管理后台 → 用户管理 → 编辑资料」里把管理员密码改成你自己的，并且**不要**把这个网址直接放到公网（见文末「关于数据存储」）。

## 功能清单

### 用户侧
- **手机号注册 / 登录 / 退出**：
  - 注册需要填 **昵称、手机号、验证码、密码、确认密码** 五项；**昵称可以重复**（不作为账号标识），手机号唯一
  - 登录用 **手机号 + 密码**；管理员等早期账号仍可用用户名登录
  - 昵称会显示在帖子、评论、配方作者处；手机号只在「我的」和后台以 `138****1234` 的形式出现
  - **验证码现在是"演示模式"**：点「获取验证码」后直接把验证码显示在页面上方（方便先跑通流程），带 60 秒重发倒计时。接上真实短信服务后自动改成真的发短信，见下方说明
- **主页 · 每日推荐**：打开网站先看到当天为你挑的 4 杯酒 —— 卡片**左图右文**（手机上图片在上、文字在下），几张卡叠在一起有层次，**左右滑动（也可以点箭头 / 圆点 / 键盘左右键）切换**；同一天推荐固定不变，第二天自动换一批。点「换一批」会立刻换一组，**换过的那批会记住，刷新页面也还在**，到第二天自动恢复成新的每日推荐。推荐卡用的是**原图**并按较小尺寸显示，所以比列表里的缩略图清晰得多
- **主页顺序**：每日推荐 → **交流区**（最新 3 条帖子，可就地发帖）→ 三个快捷入口 → 酒库统计
- **手机端体验**：窄屏下顶栏只保留站点名和右上角的菜单按钮，导航（首页 / 配方库 / 想喝啥 / 我有啥 / 添加配方 / 我的 / 管理后台）全部收进抽屉菜单，点开是一条条带序号和一句话说明的入口，不再挤成一坨
- **配方库**：关键词搜索（支持多个关键词、空格分隔、结果高亮）、经典 / 特调切换、按**基酒**筛选、按**酒感**筛选、只看收藏、只看「我有的材料能调的酒」、5 种排序（最热 / 最新 / 匹配度 / 最容易做 / 名称）
- **智能搜索**：同一个词可以有很多种写法，都能搜到 —— **中文名 / 英文名 / 各种中文译名 / 港台译名 / 常用外号 / 拼音全拼 / 拼音首字母**。例如 `金酒`、`Gin`、`琴酒`、`毡酒`、`jinjiu` 都能搜到金酒；`B52`、`轰炸机` 都能搜到 B-52；`琴蕾` 能搜到吉姆雷特；`车厘子` 能搜到用樱桃的酒。搜材料别名时，**用这个材料调的酒也会一起出现**
- **想喝啥**（按口味点单）：28 个口味标签分 5 组（口味 / 口感 / 长度 / 酒感 / 场合），随便点几个就能筛出想喝的那类；支持「同时满足全部」和「满足任一即可」两种模式，还有 **🎲 随机来一杯**——从符合标签的酒里抽一杯，专治选择困难。卡片和详情页上的标签都可以直接点，点了就跳到这里自动筛好
- **我有啥**：勾选手头材料 → 分档列出「现在就能调 / 差 1 种 / 差 2 种 / 差 3 种」；**材料搜索**（中文名 + 英文别名 + 分类）、按分类全选 / 取消、已选材料条可点击移除、**🛒 补货推荐**（告诉你再买哪几样最划算，能多解锁几款酒）
- **材料有两种筛选方式**（页面上可一键切换）：
  - **按种类**：按大类分组（基酒 / 利口酒 / 果汁与饮料 / 糖浆与调味 / 新鲜水果 / 香草与装饰 / 其他），每个大类里**仍按拼音首字母 A→Z 排列**，但**不显示字母标签**，每个大类带「全选 / 取消」
  - **按字母**：不分种类，**所有材料统一按 A→Z 排列**并显示字母分组，右侧出现 **A–Z 快速索引栏**（像 QQ 通讯录找人）：点任意字母直接跳过去，当前没有材料的字母会变灰，搜索时索引实时变化，顶部有「↑ 回到顶部」
  - 手机两列、电脑多列，两种模式下搜索（中英文/拼音/别名）都正常工作
- **配方详情**：材料清单（标出有 / 缺 / 可选）、做法步骤、教学视频外链、收藏、浏览量、评论数
- **评论区**（参考视频网站）：
  - 发表评论（500 字以内）、二级回复、点赞
  - 头像 + 昵称 + 时间（刚刚 / N 分钟前 / 昨天…）+ 身份标签
  - 按「最热 / 最新」排序，置顶评论永远在最前
  - 加载更多（每次 10 条）
  - 自己的评论可以删除；被管理员隐藏的评论只有管理员和本人能看到
- **添加配方**：必填**配方图片**（上传或贴链接，自动压缩）、**材料**（从材料库点选，可填用量、可标记「装饰用」）、**调酒步骤**（一行一步）、**口味标签**（勾选或自己写，最多 10 个）；B 站等教学视频是选填项
- **我的**：身份与权限说明、选中的材料、收藏、发布的配方、发过的评论
- **🎲 随便来一杯**：按你有的材料随机推荐

### 管理侧（admin 登录后点「管理后台」）
- **材料管理**：新增 / 编辑 / 删除（名称、分类、图标、英文别名、是否常备材料）；删除材料时用到它的配方会自动同步
- **配方管理**：查看、审核通过、下架、删除，并显示每款配方的评论数
- **评论管理**：评论概览（总数 / 今日新增 / 已隐藏 / 置顶 / 参与用户）、按内容 / 用户名 / 配方名搜索、只看已隐藏、置顶 / 隐藏 / 删除
- **用户管理**：权限说明、编辑昵称简介、重置密码、设为 / 取消管理员、删除账号
- **站点设置**：站点名称与标语，7 个权限开关（发布配方、配方审核、推荐视频、发表评论、编辑自己的配方、删除自己的配方、删除自己的评论）
- **数据备份**：导出 / 导入 JSON、恢复初始数据

## 口味标签体系

标签分 5 组共 28 个，全部内置好了，85 款酒也都打了标签：

| 分组 | 标签 |
| --- | --- |
| 😋 口味 | 甜 酸 苦 涩 咸 辣 果香 奶香 咖啡 草本 烟熏 清爽 |
| 🫧 口感 | 气泡 浓郁 绵密 冰沙 |
| ⏳ 长度 | 长饮 短饮 |
| 🥴 酒感 | 无酒精 微醺 中等 烈 |
| 🎉 场合 | 餐前 餐后 派对 独饮 夏日 冬日 |

几个用例：**「酸 + 气泡 + 夏日」** → 18 款清爽的夏日酒；**「无酒精」** → 不喝酒的人也能有得选；**「餐后 + 咖啡」** → 饭后甜点酒。标签按钮上带数字，是那个标签下有多少款酒。

用户发配方时可以**自由勾选**，也可以自己敲一个新标签（比如「家乡味」「烟熏味」），自定义标签会自动进入词库，之后所有人都能用来筛选。

## 上传配方的必填项

为了让新发上来的配方都完整可看，这四项是必填的：

1. **酒名**（英文名选填）
2. **配方图片** —— 上传手机里的照片，或者贴一个图片链接
3. **材料** —— 从材料库点选，可填用量、可标记「装饰用」
4. **调酒步骤** —— 一行一步
5. **口味标签** —— 至少 1 个，最多 10 个

**选填的有三项**：英文名、**图标 emoji**（留空会自动用第一个材料的图标，实在没有就用 🍹）、教学视频（B 站链接）。发出去之后任何用户还能继续在详情页推荐视频。

## 界面风格

整体走"深夜酒吧菜单"的路线：**近黑的墨色底 + 古金点缀**，标题用衬线字体（宋体 / Georgia），正文用无衬线保证易读。

层级主要靠**排版**而不是图标来区分：

| 层级 | 做法 |
| --- | --- |
| 页面大标题 | 衬线字体 + 字距 + 左侧金色竖线 |
| 小节标签（每日推荐 / 酒库现状） | 10.5px + 0.3em 字距的拉丁小字 |
| 分区标题（口味 / 口感 / 长度…） | 中文粗体 + 下方一行拉丁小字（TASTE / TEXTURE / LENGTH） |
| 材料大类 | 字距加宽 + 一条延伸到右端的发丝线 |
| 统计数字 | 衬线大号 + 金色 |

**emoji 只保留在"内容"上**（材料图标、没有照片时的占位酒杯），界面上的按钮、状态、标签、导航一律用文字和排版来表示。想改回带图标的风格也很容易，改 `assets/js/app.js` 里的字符串即可。

窄屏和宽屏都做了适配——手机上两列卡片、大号点击区域、单列入口，桌面上四列卡片、更宽松的留白。

动效都做得比较克制（页面进场淡入、卡片依次浮现、图片加载完成淡入、卡片 hover 图片轻微放大、按钮和标签 hover 上浮），并且**尊重系统的"减少动态效果"设置**：如果你在系统里开了弱化动画，页面会自动关掉这些效果。

## 短信验证码怎么接（可选）

注册页的验证码默认走**演示模式**（直接显示在页面上），这样不用先花钱就能把注册流程跑通。想改成真的发短信，三步：

1. 在腾讯云开通「短信」服务，申请**短信签名**和**正文模板**（都需要审核，一般 1–2 个工作日；签名可以就用你的网站名）
2. 部署项目里的 [`cloud/send-sms/`](cloud/send-sms/) 云函数，环境变量填上密钥与模板信息（代码注释里写清楚了每一项）
3. 把云函数地址填到「管理后台 → 站点设置 → 短信云函数地址」，保存即可

费用约 **0.04 元/条**（1000 次注册约 40 元）。没接之前，演示模式不影响注册流程的测试。

## 交流区（发帖 + 审核）

主页底部和顶部导航都有「交流区」入口，大家可以在这里求助、分享、聊心得、聊器材。

- **排序**：两种 —— **按时间（最新）** / **按热度（最热）**。热度 = 点赞 ×3 + 回复 ×2 + 浏览 ×0.2
- **收藏帖子**：帖子和列表上都有 ☆，收藏后能在「我的 → 收藏的帖子」看到，列表页也有「我收藏的帖子」筛选
- **酒款标签**：发帖时可以标上"调的是哪杯酒"（最多 3 个）。卡片和详情页会显示这些标签，**点标签就能看所有关于这杯酒的帖子**（地址形如 `#/posts/recipe/negroni`）
- **配方页讨论区**：每杯酒的配方页**最下方**会列出带这杯酒标签的帖子，也能直接点「就这杯酒发帖」——发帖时会**自动带上这杯酒的标签**

- **发帖**：选分类（求助 / 分享 / 心得 / 器材 / 闲聊）→ 写标题和正文 → 可选配图，**一次最多 6 张**（可一次多选，每张自动压缩到 900px 以内，缩略图上能单张删除）
- **帖子详情**：图片按网格展示，**点任意一张可以看大图**
- **帖子详情**：点赞、回复、删除自己的内容；作者自己能看到帖子的审核状态和未通过原因
- **管理后台 → 帖子审核**：概览（待审 / 已通过 / 未通过 / 今日新帖 / 回帖）、按状态筛选、按标题或作者搜索、一键通过 / 拒绝（可填原因）/ 删除，页签上带待审数量角标

### 审核是怎么做的：三层结构

| 层级 | 由谁执行 | 成本 | 作用 |
| --- | --- | --- | --- |
| 1. 规则层 | 本地 JS（已内置） | 0 | 广告词、微信/QQ/手机号、外链、违法词、刷屏重复、内容过短 —— 明显问题直接拦下或转人工 |
| 2. AI 层 | 云函数调大模型（可选） | 极低 | 规则判断不出来的"软广告、阴阳怪气、完全跑题"，交给模型算 0–100 的风险分 |
| 3. 人工层 | 管理员后台 | 0 | 复核、改判、填写拒绝原因 |

风险分对应处理：**≥70 直接拦下**（并告诉作者原因）、**30–69 转人工待审**、**<30 直接发布**。管理员自己发的帖子免审。

后台「站点设置」里可以切换审核方式：`全部先审` / `智能审核（默认）` / `不审核`。

### AI 审核怎么接（重点）

**API Key 绝对不能写在网页里。** 这个仓库是公开的，Key 一旦进前端代码，任何人按 F12 就能看到并盗刷你的额度。正确做法是 Key 存在云函数的环境变量里：

```
浏览器（发帖） ──► 云函数（持有 Key） ──► 大模型 API
                       └─► 返回 { risk, reasons }
```

项目里已经放了**可以直接部署的云函数示例**：[`cloud/review-post/`](cloud/review-post/)（零依赖，只用 Node 内置模块，支持豆包 / 腾讯混元 / 智谱 / DeepSeek）。部署步骤见该目录下的 README。部署完把地址填进「站点设置 → AI 审核云函数地址」，再打开「启用 AI 复核」即可。

### 用腾讯混元的完整步骤（约 15 分钟）

1. **拿 Key**：登录腾讯云（需实名）→ 搜「腾讯混元大模型」控制台 → 「API Key」页面创建一个，复制保存
2. **建云函数**：云开发 CloudBase 控制台 → 云函数 → 新建，名字 `review-post`，环境选 **Node.js 18**
3. **贴代码**：把 `cloud/review-post/index.js` 整段粘贴进去，保存并部署（零依赖，不用装任何包）
4. **配环境变量**：给云函数加 `AI_API_KEY`（第一步的 Key），另外两个选填：`AI_MODEL=hunyuan-lite`、`AI_BASE_URL=https://api.hunyuan.cloud.tencent.com/v1`
5. **开 HTTP 访问**：云函数 → 访问服务，拿到 `https://xxxx.service.tcloudbase.com/review-post` 这样的地址
6. **回网站打开**：管理后台 → 站点设置 → 勾选「启用 AI 复核」→ 粘贴地址 → 保存

审核标准已经按你的要求写死在云函数里（广告 / 色情 / 暴力 / 辱骂 / 灌水），要改规则不用改代码，加一个环境变量 `AI_SYSTEM_PROMPT` 覆盖即可。

| 平台 | 模型 | 说明 |
| --- | --- | --- |
| 腾讯混元 | `hunyuan-lite` | 和腾讯云开发同账号，一次实名就能用，有免费额度，**最省事** |
| 火山方舟（豆包） | `doubao-lite-32k` | 就是豆包，新用户有赠送额度，lite 版极便宜 |
| 智谱 GLM | `glm-4-flash` | 有免费额度，中文判断不错 |
| DeepSeek | `deepseek-chat` | 便宜、判断力强 |

**成本**：一条帖子约 400–600 tokens，按豆包 lite 的价位算，**一万条帖子大约几毛钱**；如果只让"规则判断不出来"的内容走 AI，还能更省。具体免费额度以各平台当期页面为准。

配方页上的图片、材料、用量、步骤、标签这些**只有管理员能改**，所以给普通用户留了一个提意见的入口：

1. 配方详情页点 **⚠️ 勘误** → 选问题类型（图片有误 / 材料有误 / 用量有误 / 步骤有误 / 标签有误 / 材料库有误 / 其他）→ 写清楚问题，可以附上"建议改成什么"→ 提交
2. 「我有啥」页面底部也有一个勘误入口，专门用来反馈**材料库**缺什么、写错了什么
3. 管理后台 → **勘误处理**：顶部有 5 个统计（待处理 / 已处理 / 已忽略 / 今日新增 / 累计），可以按状态筛选、按说明或用户名搜索，每条都能「标记已处理 / 忽略 / 重新打开 / 删除」，还能直接点进对应配方去改
4. 后台页签上有**待处理数量角标**，一眼就知道还有多少没处理

管理员依然可以直接编辑任何配方的图片与标签（详情页右上角「🖼 图片 / 标签」），勘误只是让普通用户有地方说话。

## 版本升级说明

如果你之前打开过第一版，浏览器里已经存了老数据。新版启动时会**自动升级**：

保留你的账号、自己发布的配方、收藏、勾选的材料和站点设置，然后把新增的材料、配方、评论区补进去；如果管理员密码还是旧的 `admin123`，会统一升级成 `Cocktail@2026`。

**关于"新加的酒在旧设备上看不到"**：早期版本只在"数据版本号变化"时才做升级，导致有几次新增酒谱后，老用户打开还是旧数量。现在改成了**每次打开都自动补齐新增的材料、配方和示例帖**（按 id 去重、幂等，不会重复也不会覆盖你发的内容），所以以后新增内容一定会同步到所有设备。

## 关于数据存储（重要）

原型阶段所有数据都保存在**当前浏览器的 localStorage** 里：

- 换浏览器、换电脑、清缓存会看不到数据，请用「管理后台 → 数据备份」导出 JSON；
- 密码是明文存在本机，**只适合自己本地玩，不要放公网**；
- 想让多人共享同一份数据，需要下一步接后端（见下）。

## 手机上打开还是旧版？多半是缓存

GitHub Pages 对 HTML 设了 `Cache-Control: max-age=600`（10 分钟），手机浏览器和微信内置浏览器往往还会缓存更久，所以刚推送完用手机打开，可能还是上一版。

**最稳的解决办法：在链接后面加一个版本参数**，这等于换了一个全新网址，一定不会命中旧缓存：

```
https://kiyoshi430.github.io/cocktail/?v=5
```

其它办法：

- **微信里打开**：右上角「···」→「刷新」，或者选「在浏览器打开」再刷新
- **iPhone Safari**：设置 → Safari → 清除历史记录与网站数据
- **安卓 Chrome**：设置 → 隐私和安全 → 清除浏览数据 → 勾选「缓存的图片和文件」
- **省事的办法**：等 10 分钟再打开，缓存自然过期

为了减少这个问题，`index.html` 里的 CSS / JS 都带了版本号（`style.css?v=5`）。**以后每次改完代码，我会把这个数字加 1**，这样即使 HTML 本身被缓存，样式和脚本也不会串版本。页脚右下角会显示当前版本（现在是 `v5`），可以据此确认手机是不是最新版。

## 下一步路线（已确定走腾讯云开发）

> 完整的**接后端 + 上线**步骤、数据库表设计、安全规则、成本预估和检查清单，见 👉 [`docs/上线指南.md`](docs/上线指南.md)

现在的网站是**纯前端**：账号、配方、评论都存在每个访客自己的浏览器里，所以它还不能算"真正上线可用"的网站——你和朋友看到的是两份互不相干的数据。接上腾讯云开发（CloudBase）之后，数据会集中存在云数据库里，所有人都读写同一份，登录方式也能扩展成手机号 / 微信 / QQ。

| 阶段 | 要做什么 | 说明 |
| --- | --- | --- |
| 1. 数据上云 | 云数据库建表（用户 / 材料 / 配方 / 评论 / 点赞 / 收藏），前端 `store.js` 改成调 CloudBase SDK | 只改数据层，界面代码基本不动 |
| 2. 账号体系 | 手机号验证码登录；微信 / QQ 登录（需要开放平台资质，见下方提醒） | 密码改成云端哈希，不再明文 |
| 3. 图片上云 | 换图时改为上传到云存储，返回 fileID | 不再受浏览器本地空间限制 |
| 4. 对外发布 | 云开发自带默认域名（免备案），也可绑定自己的域名 | 微信内分享、扫码访问都方便 |

### ⚠️ 登录方式的资质提醒（很重要，先看再决定）

| 登录方式 | 可行性 | 门槛 |
| --- | --- | --- |
| 手机号验证码 | ✅ 个人可做 | 腾讯云短信需实名，短信签名要审核（按条计费，约几分钱一条） |
| 微信登录（**网站**扫码） | ❌ 个人做不了 | 微信开放平台的"网站应用"只对企业/个体工商户开放，认证费 300 元/年 |
| 微信公众号 H5 登录 | ❌ 个人做不了 | 需要认证的服务号 |
| 微信登录（**小程序**内） | ✅ 个人可做 | 个人可以注册小程序，登录能力在小程序内可用 |
| QQ 登录 | ⚠️ 需确认 | QQ 互联要求网站已备案，审核较严 |

**结论**：如果你现在是个人的话，纯网站形态最现实的是**手机号验证码登录 + 邮箱/密码登录**；想在微信生态里用微信登录，更顺的路是**把界面打包成微信小程序**（现在这套界面和逻辑都是移动端适配的，用 uni-app 或 Taro 可以复用）。
