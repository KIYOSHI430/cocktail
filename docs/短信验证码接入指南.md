# 短信验证码接入指南

注册页的验证码现在是**演示模式**（直接显示在页面上），不影响功能，但体验差一点。这份文档说明怎么换成**真实发短信**。

---

## 一、先搞资质（这是唯一的门槛）

腾讯云短信要求：**短信签名**必须能证明归你所有。可选资质：

| 资质类型 | 个人能不能搞 | 说明 |
| --- | --- | --- |
| **小程序** | ✅ 能（推荐） | 你之前开发过小程序，**用它就行** |
| 公众号 | ✅ 能 | 个人可注册订阅号 |
| 已备案网站 | ⚠️ 要等备案 | 买域名 + 备案 1–3 周 |
| App | ❌ | 需要应用市场上架 |

### 用小程序申请签名（你现在的路线）

1. 腾讯云控制台 → 搜「**短信**」→ 进入短信控制台
2. 左侧「**国内短信 → 签名管理**」→「**创建签名**」
3. 签名内容填 **你小程序的名字**（必须完全一致，比如小程序叫「今晚喝什么」，签名就得是这四个字）
4. 签名用途选「**小程序**」，上传证明：
   - **小程序名称 + AppID 的截图**（微信开发者工具 → 详情 → 基本信息 那个页面）
   - 或微信里搜到你小程序后的截图
5. 提交，等审核（一般 1–2 个工作日）

> ⚠️ **注意**：短信里显示的签名是【小程序名】，不是【鸡尾酒法典】。除非你小程序改名叫「鸡尾酒法典」。
> 如果没通过，把驳回理由发我，我帮你想办法。

### 再申请一个正文模板

左侧「**正文模板管理**」→「创建正文模板」，内容建议：

```
您的验证码是{1}，{2}分钟内有效，请勿泄露给他人。
```

提交等审核（同样 1–2 天）。

审核通过后，你会拿到两个 ID：

- **签名内容**：比如 `今晚喝什么`
- **模板 ID**：比如 `1234567`

---

## 二、代码这边怎么接

**不需要新建云函数**——直接加在现有的 `api` 云函数里（我会帮你加好）。

需要你提供 4 个东西（都是上面拿到的）：

| 项目 | 从哪拿 |
| --- | --- |
| `SecretId` / `SecretKey` | 腾讯云 → 访问管理 → API 密钥管理 |
| `SMS_SDK_APP_ID` | 短信控制台 → 应用管理 → SDKAppID |
| `SMS_SIGN_NAME` | 上面申请的签名内容 |
| `SMS_TEMPLATE_ID` | 上面拿到的模板 ID |

拿到后填到云函数的**环境变量**里，我改好的代码会自动读取。

---

## 三、必须做的安全设置

短信是**按条收费**的（约 0.04 元/条），不设限制会被人刷爆。上线前一定要加：

| 限制 | 建议值 | 作用 |
| --- | --- | --- |
| 同一手机号 | 60 秒 1 条、24 小时 10 条 | 防止单人刷 |
| 同一 IP | 1 小时 20 条 | 防止批量刷 |
| 每位用户每天上限 | 10 条 | 兜底 |

另外：

1. 腾讯云短信控制台可以设置「**发送频率限制**」和「**每日消费上限**」，建议都开上
2. 在「费用 → 预算告警」里设一个 **10 元/月** 的告警，超了会发通知给你

---

## 四、接入的顺序

1. **今天**：提交短信签名 + 模板申请（要等审核，越早越好）
2. **审核通过后**：把 4 个参数发我 → 我改好代码 → 你粘贴部署
3. **部署完**：在网站后台「站点设置」里关掉演示模式（我会加个开关）
4. **测试**：用真手机号注册一次，收到短信就成功了

> 在审核通过之前，**注册功能照常可用**（演示模式只是把验证码显示在页面上），不用等。

---

## 五、成本

- 短信约 **0.04 元/条**
- 200 个新用户注册 ≈ 8 元
- 建议先在腾讯云充 **10 元**，够用很久

---

## 六、有没有更省事的替代方案？

如果你觉得短信审核太麻烦，还有一个**完全免费**的方案：

**邮箱验证码**——用你自己的 QQ 邮箱 / 腾讯企业邮，通过 SMTP 发验证码。优点：

- 不需要审核、不需要资质
- 免费（自己的邮箱）
- 代码量和短信差不多

缺点：用户要输邮箱而不是手机号，体验稍差一点；而且邮箱验证码在国内用户看来不如短信自然。

**两种方案我都能做**，你选一个告诉我。如果短信签名审核通过了，建议直接用短信；如果被拒了，我们就走邮箱。
