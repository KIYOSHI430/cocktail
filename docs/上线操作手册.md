### 第 2 步：把网页搬到腾讯云静态托管（已完成）

网页现在放在腾讯云静态托管里（和数据库在同一个云，国内打开快）。文件在控制台「静态网站托管 → 文件管理」里，根目录结构应该是：

```
/index.html
/assets/css/style.css
/assets/js/seed.js
/assets/js/store.js
/assets/js/app.js
```

> 踩过的坑：如果直接把外层文件夹拖进去，文件会被套成 `/文件夹名/index.html`，首页就会 404。正确做法是**拖 `assets` 文件夹 + 单独上传 `index.html` 文件**。

### 第 2.5 步：以后改了网页，怎么更新线上

Codex 改了代码并推送后，**腾讯云这份不会自动更新**，需要重新上传一次：

1. 让 Codex 重新生成上传包（会放在 `上传到腾讯云-网页文件` 文件夹）
2. 控制台 → 静态网站托管 → 文件管理
3. 把根目录里旧的 `index.html` 和 `assets` 删掉（或直接覆盖上传）
4. 重新「上传文件夹」选 `assets`，「上传文件」选 `index.html`
5. 手机上刷新一下（必要时清一下缓存），页脚版本号变了就说明更新成功

> 只想让别人立刻看到新内容、不想上传的话，也可以临时发 GitHub 那个地址。

### 第 3 步：域名（可选，想更正式再做）

- 买域名：腾讯云/阿里云，几十块一年
- 备案：国内服务器必须备案，免费，2–3 周
- 备案通过后在静态托管的「域名管理」里绑定，就能用 `www.你的名字.com` 访问

**不买域名完全不影响使用**，腾讯云给的默认域名就是 https，够用。

存到电脑或网盘就行。文件里含账号信息（密码是加密的），别发给别人。

## 附：已经踩过并修好的坑（留个记录）

| 报错 | 原因 | 修法 |
| --- | --- | --- |
| `Invalid schema: <环境ID>` | 云函数没指定数据库 schema | `rdb({ database: "public" })` |
| `permission denied for table sessions` | 云函数用的 anon 角色没写权限 | `grant ... to anon` |
| `column sessions.id does not exist` | 网关插入时补了 id 字段，表里没有 | 给 sessions 加 id 列 |
| `duplicate key value violates unique constraint "users_phone_key"` | 邮箱注册时手机号是空的，第二个人就撞"手机号唯一" | `cloud/sql/07-fix-phone-unique.sql` |
