## 二、上线三步走

### 第 1 步：把链接发出去（现在就能做）

发给朋友的就是这个地址：

```
https://kiyoshi430.github.io/cocktail/
```

对方打开就能注册。你在「管理后台」能看到他，能管他发的帖子、评论、配方。

### 第 2 步：把网页搬到腾讯云静态托管（推荐，免费）

**为什么**：GitHub 在国内访问经常很慢甚至打不开，而你的数据库在上海。搬过去之后网页和数据库在同一个云里，国内打开是秒开，而且地址也是 https。

**怎么做**（云开发控制台）：

1. 左侧找「**静态网站托管**」（或叫「静态托管」）→ 开通（有免费额度）
2. 「上传文件」：把项目里的这些东西传上去，**保持目录结构**：
   - `index.html`
   - `assets` 文件夹（里面有 `css/style.css`、`js/seed.js`、`js/store.js`、`js/app.js`、`js/*.js`）
3. 传完后控制台会给你一个默认域名（形如 `https://xxxx.tcloudbase.com`）
4. 用手机和电脑都打开这个新域名试一遍：能登录、能看到配方、能发帖 → 成功
5. **以后就把新域名发人**；GitHub 那个地址当作备用

> 代码里不需要改任何东西：网页请求的云函数地址是云端固定地址，搬到哪都能用。
> 搬完以后，如果你不想让别人看到源码，可以把 GitHub 仓库改成 Private（私有）。

### 第 3 步：域名（可选，想更正式再做）

- 买域名：腾讯云/阿里云，几十块一年
- 备案：国内服务器必须备案，免费，2–3 周
- 备案通过后在静态托管的「域名管理」里绑定，就能用 `www.你的名字.com` 访问

**不买域名完全不影响使用**，腾讯云给的默认域名就是 https，够用。

## 三、免费版的注意事项

| 项目 | 说明 |
| --- | --- |
| 额度 | 免费版有每月额度（数据库读写次数、云函数调用次数、静态托管流量）。用超了可能停服，控制台里能看到用量 |
| 自动备份 | **免费版不支持**，所以用下面的手动备份代替 |
| 什么时候升级 | 等真有几十个活跃用户、或者用量接近上限了再升级成按量付费，初期用量很小，花不了多少钱 |

### 手动备份（重要，建议每 1–2 周做一次）

管理员登录 → **管理后台 → 数据备份 → 下载完整备份（JSON）**

会下载一个 `cocktail-backup-日期.json`，里面有全部材料、配方、帖子、评论、账号、设置。
存到电脑或网盘就行。文件里含账号信息（密码是加密的），别发给别人。

## 附：已经踩过并修好的坑（留个记录）

| 报错 | 原因 | 修法 |
| --- | --- | --- |
| `Invalid schema: <环境ID>` | 云函数没指定数据库 schema | `rdb({ database: "public" })` |
| `permission denied for table sessions` | 云函数用的 anon 角色没写权限 | `grant ... to anon` |
| `column sessions.id does not exist` | 网关插入时补了 id 字段，表里没有 | 给 sessions 加 id 列 |
| `duplicate key value violates unique constraint "users_phone_key"` | 邮箱注册时手机号是空的，第二个人就撞"手机号唯一" | `cloud/sql/07-fix-phone-unique.sql` |
