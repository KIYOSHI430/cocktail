# 邮箱验证码接入指南

登录方式已经从**手机号**改成了**邮箱**，验证码走邮件发送。

现在处于**演示模式**：还没配发件邮箱，所以验证码会**直接显示在注册页上**（"演示模式：验证码是 XXXXXX"），功能完全跑得通，你先用着就行。

等你想让别人真实收到邮件，按下面三步做，**全程在网页上点，不用改代码**。

> 为什么不用短信？腾讯云短信现在的签名只支持「公司 / 政府 / 事业单位 / 商标」这类资质，个人开发者走不通，而且审核通过后还要运营商实名报备 7–10 个工作日。邮箱验证码是个人能立刻做通的方案，还免费。

---

## 第一步：在 QQ 邮箱拿到「授权码」

授权码是给程序用的专用密码，**不是你的 QQ 密码**。拿到后不要发到聊天里、不要写进网页代码。

1. 电脑浏览器打开 QQ 邮箱 → 右上角「**设置**」→「**账号**」
2. 找到「**IMAP/SMTP 服务**」这一栏 → 点「**开启**」
3. 按提示用绑定的手机发一条短信验证
4. 验证通过后会弹出一串 **16 位授权码**，复制保存好（**只显示一次**，忘了就重新生成一个）

> 如果你用的是其他邮箱也行：163 邮箱在「设置 → POP3/SMTP/IMAP」里开，Gmail 在「账号 → 安全性 → 应用专用密码」里开。

---

## 第二步：把授权码填进云函数的环境变量

1. 打开腾讯云开发控制台 → 左边「**云函数**」→ 点 **`api`** 这个函数
2. 上方切到「**函数配置**」→ 找到「**环境变量**」→ 点「**编辑**」
3. 加两条（键值对）：

   | 变量名 | 值 |
   | --- | --- |
   | `SMTP_USER` | `3246713776@qq.com` |
   | `SMTP_PASS` | 刚才那串 16 位授权码 |

   （可选，默认就是 QQ 邮箱，不用填）
   | 变量名 | 值 |
   | --- | --- |
   | `SMTP_HOST` | `smtp.qq.com` |
   | `SMTP_PORT` | `465` |

4. 保存 → 点「**部署**」让配置生效

> 为什么放环境变量而不是写进代码？因为 GitHub 仓库是公开的，代码里的任何密码都会被别人看到。环境变量只存在云函数里，外部读不到。

## 常见问题

| 现象 | 原因 / 解决 |
| --- | --- |
| 提示「验证码刚发过，请 60 秒后再试」 | 正常的频率限制，等一分钟 |
| 提示「未配置 SMTP_USER / SMTP_PASS」 | 环境变量没保存或没重新部署 |
| 提示 SMTP 第 2 步返回 535 | 授权码不对（用了 QQ 密码？），重新生成一个 |
| 收不到邮件 | 先看垃圾箱；QQ 邮箱对新账号有发信频率限制，隔几分钟再试 |
| 提示「数据库还没有 email 字段」 | `cloud/sql/06-email-login.sql` 还没执行，去 SQL 编辑器里跑一遍 |
