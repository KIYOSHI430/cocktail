# 上线收尾清单

数据上云已经完成 ✅ 下面是正式对外开放前要做的最后几件事。

---

## 一、必须做的（5 分钟，在控制台点）

### 1. 云函数执行超时改成 20 秒

**为什么**：现在是 **3 秒**，而前端首次打开要拉 192 种材料 + 115 款配方，可能来不及。

**怎么做**：云函数/托管 → 点 `api` → 函数配置 → 右上角「编辑」→ 执行超时改成 **20 秒** → 保存。

### 2. 确认「匿名登录」是关闭的

**为什么**：云函数以 `anon` 身份访问数据库，我们刚给 `anon` 开了写权限。如果前端也能用匿名身份连数据库，别人就能绕过云函数直接改数据、甚至读到密码哈希。

**怎么做**：云开发控制台 → 左侧「**身份认证**」→ 看「**匿名登录**」是不是**关闭**状态。**保持关闭**（我们前端不用它，所有请求都走云函数）。

### 3. 设置数据库每日自动备份

**怎么做**：SQL 型数据库 → 左侧「**备份**」→ 开启自动备份（建议每天一次，保留 7 天）。

### 4. 删掉演示账号 demo

在 SQL 编辑器里执行（已给过你）：

```sql
delete from users where id = 'u-demo';
```

### 5. 短信消费限制

如果接了短信：短信控制台 → 设置「发送频率限制」+「每日消费上限」，并在「费用 → 预算告警」设 10 元/月提醒。
